# Phone-to-PC Wi-Fi Sync Guide (Syncthing)
## Team RAGTAG — Offline Privacy-First WhatsApp AI & Task Command Center

This guide details the setup and operational workflow for establishing an automated, continuous, 100% private, zero-cloud synchronization pipeline between an Android smartphone and your local Windows PC using **Syncthing**.

---

## 1. Architectural Context & Security Model

Team RAGTAG is designed to operate in completely air-gapped and privacy-preserving environments. Standard cloud-based sync tools (Google Drive, Dropbox, OneDrive, iCloud) upload unencrypted or platform-managed data to remote corporate servers, creating external attack surfaces and privacy risks.

```
  ┌─────────────────────────────────┐                 ┌──────────────────────────────────┐
  │         Android Phone           │                 │            Windows PC            │
  │                                 │                 │                                  │
  │  /WhatsApp/Databases/           │                 │  <PROJECT_ROOT>/backend/backups/ │
  │   ├── msgstore.db.crypt15       │  TLS 1.3 Sync   │   ├── msgstore.db.crypt15        │
  │   └── encrypted_backup.key      ├────────────────►│   ├── encrypted_backup.key       │
  │                                 │  (Local Wi-Fi)  │   └── sample_chat.txt            │
  │  [Syncthing: Send-Only Folder]  │                 │  [Syncthing: Receive-Only Folder]│
  └─────────────────────────────────┘                 └─────────────────┬────────────────┘
                                                                        │
                                                                        ▼
                                                             [wadecrypt / Ingestion]
                                                             [msgstore_ragtag.db + ChromaDB]
```

### Why Syncthing?
- **Decentralized & Peer-to-Peer**: Directly connects your phone and PC across your local Wi-Fi router (LAN). No intermediate relay or cloud storage is ever required.
- **TLS 1.3 Cryptographic Security**: Every transmission between paired devices is authenticated and strongly encrypted using mutual TLS 1.3 certificates. Eavesdroppers on the Wi-Fi network cannot inspect or tamper with files.
- **Zero Cloud / Zero Subscriptions**: 100% free, open-source software (MPL-2.0) that respects data sovereignty.
- **Send-Only / Receive-Only Topology**: The phone strictly serves as a **Send-Only** source, and the PC operates as **Receive-Only**. Your PC can never delete, modify, or corrupt WhatsApp databases on your mobile device.

## 2. Target WhatsApp Data Files

Syncthing synchronizes files into the RAGTAG backend staging directory:
`<PROJECT_ROOT>\backend\backups\`

The target files include:
1. **Encrypted WhatsApp Database**:
   - `msgstore.db.crypt14` or `msgstore.db.crypt15`
   - Located on Android in: `/storage/emulated/0/Android/media/com.whatsapp/WhatsApp/Databases/`
   - Automatically regenerated by WhatsApp daily at 2:00 AM, or manually triggered at any time.
2. **64-Hex End-to-End Encryption Key**:
   - `encrypted_backup.key`
   - Generated when enabling WhatsApp's 64-digit End-to-End Encrypted Backup.
3. **Exported Text Chats (Optional / Auxiliary)**:
   - Exported `.txt` files from individual group chats (e.g. `WhatsApp Chat with CS-401.txt`).
   - Placed in a mobile staging folder (e.g. `/storage/emulated/0/RAGTAG_Sync/`).

## 3. Step-by-Step Android Setup

### 3.1 Install Syncthing
1. **Recommended Client**: Install **Syncthing-Fork** by Catfriend1 via **F-Droid** or the **Google Play Store**.
   - *F-Droid*: Search for `Syncthing-Fork` (preferred for unrestricted background synchronization).
   - *Google Play Store*: Search for `Syncthing-Fork`.
2. Open Syncthing-Fork and complete the initial setup wizard.

### 3.2 Configure Permissions & Battery Exemption
Modern Android versions (Android 11, 12, 13, and 14) enforce strict Scoped Storage and battery limits that can sleep background synchronization. Configure the following:
1. **All Files Access (`MANAGE_EXTERNAL_STORAGE`)**:
   - In Syncthing, navigate to app settings or system prompts.
   - Select **Grant All Files Access** so Syncthing can read the WhatsApp media folder.
2. **Disable Battery Optimization**:
   - Go to Android `Settings` -> `Apps` -> `Syncthing-Fork` -> `App battery usage` (or `Battery Optimization`).
   - Change from *Optimized* to **Unrestricted** (or *Don't Optimize*).
   - This prevents Android OS from suspending the Syncthing sync service when the screen turns off.
3. **Network Constraints (Wi-Fi Only)**:
   - In Syncthing-Fork: Go to `Settings` -> `Run Conditions`.
   - Enable **Run only on Wi-Fi**.
   - (Optional) Under **Allowed Wi-Fi Networks**, select your trusted Home or Campus SSID to ensure synchronization only runs on known local subnets.

### 3.3 Create and Map the Synced Folder
1. Open the Syncthing-Fork app and tap the **+** (Add Folder) button.
2. Configure folder parameters:
   - **Folder Label**: `WhatsApp Backups`
   - **Folder ID**: `whatsapp-backups` (auto-generated or custom string; keep identical on both devices)
   - **Folder Path**: Tap directory picker and navigate to:
     ```
     /storage/emulated/0/Android/media/com.whatsapp/WhatsApp/Databases/
     ```
     *(Alternative staging option: `/storage/emulated/0/RAGTAG_Sync/` if you prefer copying files or exported `.txt` chats manually).*
   - **Folder Type**: Select **Send Only**.
     > **Critical Security Check**: Setting the phone to "Send Only" ensures that any changes, deletions, or tests on your PC never touch or alter your actual phone database.
   - **Watch for Changes**: **Enabled** (uses Android file-system inotify events to sync immediately when WhatsApp completes its backup).
   - **Rescan Interval**: `3600` seconds (1 hour safety fallback).
3. Tap **Save / Checkmark**.

## 4. Step-by-Step Windows PC Setup

### 4.1 Install Syncthing on Windows
Choose either package:
- **Option A (winget - Recommended)**:
  Open PowerShell as Administrator and run:
  ```powershell
  winget install Syncthing.Syncthing
  ```
- **Option B (SyncTrayzor GUI)**:
  Download and install SyncTrayzor from GitHub releases (provides system tray integration and automatic startup).

### 4.2 Initialize the Web GUI
1. Launch Syncthing from the Start Menu or run `syncthing.exe`.
2. Open your web browser and navigate to:
   ```
   http://127.0.0.1:8384
   ```
3. (Recommended) Set a local GUI authentication username and password when prompted.

### 4.3 Pair PC with Android Phone
1. **Retrieve PC Device ID**:
   - In the PC Syncthing Web GUI, click **Actions** (top right) -> **Show ID**.
   - A QR code and a 50+ character alphanumeric Device ID appear.
2. **Add Device on Phone**:
   - Open Syncthing on Android -> navigate to the **Devices** tab -> tap **+**.
   - Tap the QR code icon and scan your PC monitor, or paste the Device ID.
   - Device Name: `RAGTAG-Windows-PC`.
   - Tap **Save**.
3. **Accept Pairing on PC**:
   - Within 10 seconds, a notification banner appears on the PC Web GUI: *"Device 'My Android Phone' wants to connect"*.
   - Click **Add Device**.
   - Verify the Device ID matches and click **Save**.

### 4.4 Accept and Map Shared Folder
1. Once paired, trigger sharing from Android:
   - In Syncthing on Android, open the `WhatsApp Backups` folder settings.
   - Under **Share with Devices**, toggle your PC device on. Tap **Save**.
2. **Accept Folder on PC**:
   - A notification banner appears on `http://127.0.0.1:8384`: *"Device wants to share folder 'WhatsApp Backups' (folder ID: whatsapp-backups)"*.
   - Click **Add Folder**.
3. **Configure Local Folder Path**:
   - **Folder Label**: `WhatsApp Backups`
   - **Folder Path**: Set the absolute path to your project backend backups directory:
     ```
     c:\Users\<YOUR_USER>\OneDrive\Desktop\MACRO PROJECT 3rd sem Team RAGTAG\backend\backups
     ```
   - **Folder Type**: Under the **Advanced** tab, set Folder Type to **Receive Only**.
   - **File Versioning**: Under the **File Versioning** tab, select **Simple File Versioning** (Keep 3 versions). This provides instant rollback safety if a corrupted backup file is ever synced.
4. Click **Save**.

The status will transition to **Syncing (100%)** and display **Up to Date**.

## 5. WhatsApp 64-Hex End-to-End Encryption Key Setup

WhatsApp encrypts local backup files using AES-256-GCM. To enable RAGTAG to decrypt these files locally without cloud keys:

### 5.1 Enable 64-Digit E2EE Backup in WhatsApp
1. Open WhatsApp on your Android phone.
2. Go to **Settings** -> **Chats** -> **Chat backup**.
3. Tap **End-to-end encrypted backup**.
4. Tap **Turn On**.
5. When prompted for password vs 64-digit key, select **Use 64-digit encryption key instead**.
6. WhatsApp displays your unique 64-character hexadecimal key (e.g., `3a8f...9b2c`).
7. **Take a screenshot or note this key down safely**. Tap **Continue** and confirm backup creation.

### 5.2 Store Key in RAGTAG Backend
1. On your PC, navigate to:
   ```
   backend\backups\
   ```
2. Create or edit a plain text file named:
   ```
   encrypted_backup.key
   ```
3. Paste the exact 64-character hexadecimal key as a single continuous line (no spaces, no quotes, no trailing newlines).
   Example format:
   ```
   e1c3a789f4b238dc01827463529a1b0c98e7d6f543210abcedf876543210fedc
   ```
4. Save the file.

### 5.3 Decryption Pipeline (`wadecrypt`)
The RAGTAG backend relies on `wa-crypt-tools` via `decrypt_pipeline.py`. When triggered, it executes:
```bash
wadecrypt backend/backups/encrypted_backup.key backend/backups/msgstore.db.crypt15 backend/msgstore.db
```
This produces the decrypted SQLite database (`backend/msgstore.db`) containing raw chat tables (`message`, `jid`, `chat`), which `backend/ingest.py` ingests into RAGTAG's relational ground truth.

## 6. End-to-End Sync Verification Walkthrough

Follow these steps to test and verify your continuous sync pipeline:

```
[Phone Backup] ──► [Wi-Fi Syncthing] ──► [PC backups/] ──► [Web UI Sync Page] ──► [Decrypted & Ingested]
```

### Step 1: Trigger Manual Backup on Phone
1. In WhatsApp: **Settings** -> **Chats** -> **Chat backup**.
2. Tap the green **Back Up** button.
3. WhatsApp will package and encrypt the local database into `msgstore.db.crypt15`.

### Step 2: Observe Syncthing Transfer
1. Open Syncthing on Android or PC (`http://127.0.0.1:8384`).
2. Within 5 to 15 seconds over local Wi-Fi, the status shows **Syncing**, transferring bytes across your local network.
3. When complete, confirm file existence in Windows File Explorer:
   ```
   dir backend\backups\msgstore.db.crypt15
   ```

### Step 3: Verify Status in RAGTAG Command Center
1. Launch the RAGTAG stack via `start.bat` (or verify servers are running on `http://localhost:3000` and `http://127.0.0.1:5000`).
2. In your browser, open:
   ```
   http://localhost:3000/sync
   ```
3. Check the telemetry status cards:
   - **Backup File Status**: Displays green badge `Detected (msgstore.db.crypt15)`.
   - **Encryption Key Status**: Displays green badge `Key Found (encrypted_backup.key)`.

### Step 4: Run Decrypt & Ingest
1. Click the **Run Decrypt** button.
   - The UI invokes `POST /api/decrypt`.
   - The log terminal displays: `[+] Success! Decrypted database saved to: msgstore.db`.
2. Click the **Run Ingest & Index** button.
   - The UI invokes `POST /api/ingest`.
   - Output log indicates: `[SUCCESS] Ingestion Complete! Contacts Added: X, Messages Ingested: Y`.
3. Click the **Run Task Extractor** button or open the **Dashboard** / **Calendar** to inspect newly extracted tasks!

## 7. Troubleshooting & Common Pitfalls

| Issue | Root Cause | Solution |
|---|---|---|
| **Syncthing stuck on "Disconnected"** | Windows Firewall blocking local TCP discovery (port 22000) | Allow Syncthing through Windows Defender Firewall for Private Networks. |
| **"Folder path missing" on Android** | Android Scoped Storage restriction | In Android Settings, grant Syncthing **"All files access"** (`MANAGE_EXTERNAL_STORAGE`). |
| **Sync stops when phone screen sleeps** | Android aggressive battery optimization | Set Syncthing battery usage to **Unrestricted** / **Don't Optimize**. |
| **Decryption fails (`wadecrypt` error)** | Key file has trailing newline, spaces, or wrong format | Open `encrypted_backup.key` in VS Code / Notepad and verify it contains exactly 64 hexadecimal characters on one line. |
| **Files sync across internet instead of LAN** | Devices on different Wi-Fi bands (e.g. 2.4 GHz vs 5 GHz guest isolation) | Ensure both devices connect to the same router subnet with AP isolation disabled. |
| **Out-of-Sync / Conflict files generated** | Dual write conflicts | Ensure Android folder is set to **Send Only** and PC folder is set to **Receive Only**. |
